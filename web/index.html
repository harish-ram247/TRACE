      How it works

      1. 01Resolve the dateFrom the date field, or from the question: “before Vite 3”, “in March 2022”.
      2. 02Retrieve what was valid thenEvery section of the docs is versioned from git history with the dates it was valid; search only sees versions valid on that date.
      3. 03Verify each claimAn entailment model checks every claim against the cited source, and that the source was valid on that date.
