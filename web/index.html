      How it works

      1. Resolve the date. From the date field, or from the question: “before Vite 3”, “in March 2022”.
      2. Retrieve what was valid then. Every section of the docs is versioned from git history with the dates it was valid; search only sees versions valid on that date.
      3. Verify each claim. An entailment model checks every claim in the answer against the cited source, and that the source was valid on that date.
